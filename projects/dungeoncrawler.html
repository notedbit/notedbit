C++ Dungeon Crawler

I developed the original game independently as coursework. The maze, turn-based combat and inventory mechanics can be explored in a later JavaScript adaptation.

2022/23Original archived · Browser version playableC++ · AlgoViz/SVG · JavaScript

JavaScript browser adaptation

Actual game screen from the later adaptation. It uses the existing pixel-art assets and reproduces selected mechanics of the C++ project.

Generating a playable maze

The original C++ project used a grid to represent the dungeon and separate classes for the player, enemies and items. Randomized level generation includes reachability checks so the map can be traversed.

Origin and scope

The project was part of Algorithms and Data Structures at the University of Osnabrück. It used AlgoViz/SVG for graphics. The browser adaptation runs separately and its source is part of the website repository.
