Independent development project

Python Simulation Prototype

Python prototype with nine registered simulation modes, configurable recipes and run metrics. Physics, collisions and some modes are currently unreliable.

Pythonpygame-ceEventsCollision logic

2026 · Development workIncomplete prototype · Demo unavailable

Simulation mechanics

The Python source registers nine modes: Escape / Multiplication, Fibonacci / Merge, Bounce Evolution, Shrinking Circle, Power Doubler, Mass Collision Counter, Plinko, Polygon Evolution and Multiplier Rings. The last mode is explicitly marked experimental.

Events and reproducibility

A mode registry, configurable recipes, seeded runs, collision helpers, event listeners and run-quality metrics are implemented in Python. The desktop application opened a window on Kubuntu. Simulation behavior remains unverified.

Current limitations

MP4 export was part of the planned workflow. A working export has not been verified. The separate three-mode JavaScript adaptation has been withdrawn from the demo listings due to known defects.
