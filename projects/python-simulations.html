Python Simulation Prototype

Python experiment with nine registered simulation modes, configurable recipes and run metrics.

2026Incomplete prototypePython · pygame-ce

Tracking simulation events

I organized the modes in a registry and used seeded runs and event listeners to track collisions, spawning and removal. The ninth mode is marked experimental in the source.

Known limits

The desktop application opened a window on Kubuntu. Physics, collisions and some modes remain unreliable. A working MP4 export has yet to be demonstrated. The separate three-mode JavaScript adaptation is archived.
